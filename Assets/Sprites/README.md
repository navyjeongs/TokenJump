# TokenJump game sprites

These SVGs were drawn specifically for TokenJump from basic vector shapes; no external asset pack or service logo is included.

- `platform.svg`: ordinary wooden/stone ledge
- `platform-rail.svg`: metal moving ledge
- `platform-ice.svg`: ice ledge
- `platform-goal.svg`: goal ledge
- `cannon.svg`: cannon facing right; the game mirrors it for the opposite side
- `spikes.svg`: steel spikes
- `cannonball.svg`: cannonball
- `goal-flag.svg`: goal marker

Edit the SVG source and run `./build-app.sh`. The build tool converts the sprites to cached 3× PNG textures and bundles them with the app. The game has no SVG/web rendering work during play. The supported SVG primitives are rect, circle, polygon, and line; unsupported elements fail the build rather than silently disappearing.

`../Sprites-preview.png` is generated by the same tool. Test all runtime textures with `.build/release/TokenJump --art-test`.
